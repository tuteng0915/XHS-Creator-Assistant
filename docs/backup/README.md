# Backup Documentation

These files are retained as historical reference. They are not the current
source of truth for implementation decisions.

- `current-prototype.md` records the behavior of the original single-file
  `index.html` prototype.
- `migration-plan.md` records the original incremental migration plan. Most
  slices have been superseded by the current implementation.
- `workspace-model.md` records the early minimum workspace design. It predates
  the current Skill / Agent / Workflow capability asset layer and maker agents.

For current decisions, start with `../architecture-review.md`.
