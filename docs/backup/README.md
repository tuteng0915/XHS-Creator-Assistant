# Backup Documentation

These files are retained as historical reference. They are not the current
source of truth for implementation decisions.

- `current-prototype.md` records the behavior of the original single-file
  `index.html` prototype.
- `migration-plan.md` records the original incremental migration plan. Most
  slices have been superseded by the current implementation.
- `workspace-model.md` records the early minimum workspace design. It predates
  the current Skill / Agent / Workflow capability asset layer and maker agents.
- `input-asset-model.md` records the early input asset model (2026-08).
- `agent-context-access.md` records the early Context Access Layer design for
  agents reading workspace assets (2026-08).
- `llm-context-audit.md` records the 2026-08 audit of LLM context management.
- `product-evolution.md` records the 2026-08 product evolution plan.
- `skill-catalog.md` records the 2026-08 catalog of creator product skills.

For current decisions, start with `../project-overview.md` (current state) and
`../roadmap.md` (next steps). `../architecture-review.md` is itself a 2026-08
historical review.
