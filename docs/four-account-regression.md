## 人物池与已知偏差

QSheep 使用 5 位既有早期人物，秀才加点冰使用 8 位既有人物，一粒鱼使用 3 位既有人物。它们不等同于最新生成提示的结果，有些仍较话题化、相互重复。保留这些真实缺点，不为测试临时手工换成更漂亮的人物。

Ag 没有保存人物。仅对其排除两篇测试笔记后的最近 10 篇已存笔记及相应评论进行一次受众生成，校验后保留有效角色供本次检查使用，不创建正式粉丝资产，不因不足八位自动补生成。

所有试读均移除主样本及保留样本对应的历史评论配对，避免直接把该篇真实评论交给模型作为答案。但已保存人物本身可能由这些内容归纳而来，不能声称四账号都是未见样本的盲测。保留样本只是本轮未调用的新测试输入，也可能出现在更早的账号分析里。

## 执行边界

第一批固定自然全文试读、关闭互相回应，每篇最多推荐两位，再分别试读并汇总。上限为四次推荐、八次独立反应、四次编辑汇总，加 Ag 一次人物生成，总计最多 17 次模型请求。允许少选或无匹配，不补造人物。此批不验收账号画像生成、互相回应、改稿采用或前后复测全链路。

每阶段保存原始响应、模型名、系统提示指纹、耗时和接口用量。来源及定位校验通过只是结构检查，以下仍需人工逐条读：

- 推荐理由是否忠实于当前正文，人物组合是否有不同判断，而不是两个近义标签。
- 留言是否像普通读者，不是两位编辑审稿；已满足需求是否与当前内容对应。
- 疑问是否合理，是否把未读取的图片内容当成作者没有写。
- 编辑是否保留表达优势，是否把个别人的额外兴趣强制变成作者必须补齐的信息。
- 建议是否添加了输入未支持的事实、具体阈值、资历、承诺或当前产品信息。

不在同一批中修改产品提示。模型失败停止该账号剩余步骤，不重复请求；其他账号作为独立案例继续。检查脚本本地字段错误允许修正后复用已返回的相同输入响应，只发尚未执行的步骤，所有新请求仍算在原 17 次上限内。缓存复用不是新模型调用，原失败报告不覆盖。

## 检查入口

`scripts/check_four_account_panel.py` 默认只做免费冻结／预览；只有显式 `--live` 才调用当前 Qwen。数据库仅在冻结时只读访问，模型阶段读取快照，不导入应用启动入口。新输出目录不得覆盖旧报告。结果及具体测试命令记录在[当前状态与 TODO](status-and-todo.md)。

本轮完成后优先从四账号共有或高影响问题里选一个修正，再检查保留样本。不要把各账号表现差异抹平成一个平均分，也不要以“都能返回 JSON”宣布四种内容均已验收。

四篇的八位读者全部公开留言，且多为较长的分析式提问。这是本批样本表现，不是对真实评论率的推断；它提示当前人物和任务仍有评审化倾向。Ag 一次生成八位、五位通过证据校验，另三位因引文不精确被拒；五位只保存在检查报告中，正式读者池仍为零。

本批是只看已存标题／文字的诊断，没有观察图片。尤其影视导读和项目列表可能只给到了图文帖的文字引言，不能据此确定整篇作品确实缺乏论证。没有进行站外事实核验，结论是“输出缺少本次输入依据”，不是把模型生成的条款、学制等当作事实转述。本批也未传入账号定位摘要，推荐依赖本账号人物池和当前文字。

下一优先级是编辑补事实边界：将“需要作者补素材”和“可以基于现有文字改写”分开，保留有价值的问题，不在 suggestedText 中替作者编答案。其次处理文字材料完整性和同题组队的近义人物重复。四篇保留样本本轮未调用；后续在上述改进后检查，不以这四篇原题的反复成功代替泛化检验。

核对模型的素材问题仍夹带猜测数值与“您提到……”式错误前提。因此最终程序不直接展示核对模型编写的问题，而保留具体解释与原文锚点，使用固定中性素材提示。离线重放同批四份编辑决定，七张补素材卡均为空白替换稿和中性问题，没有新增模型调用。原始实测报告不覆盖。代价是问题措辞较通用，核对解释仍可能过度要求作者举证；QSheep 推荐理由还把开源推断成免费。不能称为完整事实正确性或读者召回验收。

首次实验报告 `data/evals/panel-quality-20261006/report.json` 保留十次请求尝试、九项阶段失败；发现核对提示缺少 JSON 字样，与当前 JSON 输出模式不配套，修正后以上批次完成。首批未保存原始错误响应及用量，不能确定全部错误根因、计费或声称零费用。本轮合计 20 次 HTTP 尝试，无自动重试。检查脚本现遇首个失败就停止、记录安全诊断，并有 JSON 提示、预算与截断回归。

`scripts/check_panel_quality.py` 默认只预览，显式 `--live` 才调用，最多八次冻结核对及可选两次完整选人。原四账号脚本和配对脚本现在按实际 HTTP 次数计预算，缓存还需匹配核对提示指纹；不会因额外核对暗中突破原 17／6 次上限。全新四账号或两版配对现在可能在上限处停止，不应将不完整报告当成功。下一步先检查相邻兴趣的合理读者会否被误排除，再单独确定完整复测预算。
