## 如何复现

虚构材料及接口替身位于 `frontend/src/readme-preview/`，入口是 `frontend/readme-preview.html`。它不接入正式导航，也不进入默认生产构建。

安装前端依赖后，仅启动前端即可；不需要数据库、后端或密钥：

```bash
npm --prefix frontend run dev -- --host 127.0.0.1 --port 5187 --strictPort
```

- 创作主图：`http://127.0.0.1:5187/readme-preview.html?view=writing`
- 账号报告：`http://127.0.0.1:5187/readme-preview.html?view=account`
- 读者群聊：`http://127.0.0.1:5187/readme-preview.html?view=panel`

入口在挂载组件前拒绝所有 `fetch`，业务接口仅使用明确列出的内存替身；未实现的发送、生成等操作直接报“演示不连接后端”，不回退到真实接口。演示中的编辑和保存仅在内存中生效，刷新恢复；仅清理此虚构工作区的页面暂存，不触碰真实档案。

截图使用桌面浏览器完整页面，局部图直接截取组件区域；检查文字、引用、画面标记后覆盖对应 JPG。前端回归包含 `ReadmePreview.test.tsx`：检查网络拒绝、原文引用、三项参考与未采用建议、群聊及其反馈来源。文档界面演示不等于模型效果验收。
