# README 视觉素材

这些素材用于项目说明，不是模型质量评测，也不是正式账号记录。

| 文件 | 用途 | 来源 |
| --- | --- | --- |
| `cover.svg` | README 封面 | 仓库原生 SVG，蓝绿色概念插图，无外部字体或图片 |
| `account-analysis.jpg` | 账号分析示例 | 现有 `AccountPortraitView` 组件 + 虚构演示内容 |
| `audience-readers.jpg` | 读者候选示例 | 现有 `AudienceGroups` 组件 + 虚构演示内容 |
| `reader-panel.jpg` | 试读群聊示例 | 现有 `SimulationChat` 组件 + 虚构演示内容 |

演示账号、笔记和互动数围绕日常记录与做事习惯编写，不取自正式数据库；画面保留演示标记。截图外围为文档展示容器，不代表新增的应用导航或功能。人物头像复用产品已有的本地 SVG 组件。

更新时直接渲染当前组件与公开可用的虚构材料，再从浏览器截图；不要把真实账号数据、评论、内部 ID、登录态或配置页面放进 README。保持组件原有字号、颜色与交互布局，不用图片后处理把缺失功能补成“已实现”。

封面可以直接修改 SVG；截图调整应回到组件和演示数据。图片以相对路径引用、点击可查看原尺寸，不依赖外部图床。无需为了更新文档调用模型、抓取新数据或启动正式后端。
