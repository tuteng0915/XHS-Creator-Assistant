# 路线图

更新日期：2026-11-07。现状见[项目总览](project-overview.md)。本文只列待做的事和顺序；做完后把结果记进[状态记录](status-and-todo.md)，并从这里删除或更新对应条目。

排序原则来自用户的长期要求：先处理交付失败、事实可靠性和实际等待，再做新功能；不把“加功能”或“再加一轮校验调用”当作默认推进方式；真实模型实验要小规模、问题明确、事先说清预算。

## P1 质量与可靠性

1. **验收账号诊断的图片文字与局部恢复**
   - 做法：在临时库中选1～2篇正文主要写在图片里的笔记，核对原图 → 识别文字 → 报告引用；再人为制造一个阶段失败，确认成功部分不重复调用、失败部分可以恢复。
   - 验收：保存模型原文、调用次数和等待时间，由用户判断识别质量。
   - 前提：用户确认样本和调用预算，模型沿用DeepSeek。
2. **创作的事实可靠性**
   - 做法：先列出资料包里任务、事实来源、说话人和原稿版本是怎样区分的，再用已知出错的稿件和确有亲历的正例回放。
   - 验收：对照完整成稿、等待时间和人工采用情况，不以禁词是否消失为准。
   - 参考：[事实来源回归](creator-source-attribution-regression-20261017.md)、[推断事实化回归](creator-inference-facts-regression-20261017.md)、[改稿去重回归](creator-revision-dedup-20261017.md)。
