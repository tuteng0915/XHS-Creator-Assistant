# 创作者聚焦版 V2 执行手册

## 1. 版本目标

这一版把现有“创作者工作区 + 能力资产调试台”收口为面向小红书创作者的单一产品流程。旧功能、旧 API、旧数据库记录和 LangGraph 实现不删除，只关闭公开入口，确保未来仍可恢复或供内部调试使用。

公开产品只讲一件事：导入一个小红书账号，理解它过去一段时间的内容表现，帮助创作者确认定位、找到下一批选题、用 AI 细化创作方案，并通过受众模拟预判反馈。

主链路固定为：

1. 导入小红书账号；
2. 查看账号历史材料和数据范围；
3. 运行账号诊断，识别定位、内容支柱、优势、问题和爆款模式；
4. 生成并保存候选选题；
5. 用 AI 把选题细化为创作 Brief 和内容结构；
6. 基于账号受众运行受众模拟，查看可能评论、疑虑和方向性数据预估；
7. 所有分析、选题、创作输出和模拟结果都可重新打开。

热点分析和视频博主内容质量诊断不再出现在公开入口。Skills、Agents、Workflows、Capability Maker、Asset Proposal 和内部对话调试界面也不再出现在公开入口，但其代码、表、API 和测试继续保留。

## 2. 产品边界

### 2.1 使用者

当前默认只有一个本地产品用户，不做登录、注册、权限和协作。数据库仍保留“用户拥有多个创作者账号空间”的所有权关系，以便未来增加登录时不需要重写资产归属。

用户在界面中感知的顶层单位不是 Workspace，而是“小红书账号档案”。一个账号档案对应一个后端 Workspace；该 Workspace 下的输入材料、分析、选题、Draft、受众模拟和媒体资产天然隔离，不跨账号读取或复用。

### 2.2 对外可见能力

对外只暴露以下功能：

- 小红书账号档案选择、新建和导入；
- 账号材料与抓取范围查看；
- 账号诊断；
- 分析历史；
- 选题库；
- AI 创作细化；
- 受众模拟及历史；
- 当前页面帮助。

### 2.3 关闭但保留的能力

以下功能仅关闭导航和公开调用入口，不删除实现：

- 热点分析及趋势数据入口；
- 视频博主质量诊断及视频创作样本入口；
- 图文/视频多模态实验入口；
- Skills / Agents / Workflows 管理页；
- Capability Maker、Asset Proposal 和开发者对话页；
- 批量导入与批量 workflow 相关兼容 API。

历史 AnalysisRun 中的 `trend_analysis` 和 `video_creator_quality` 记录仍可在数据库中保留。公开分析历史默认只显示账号诊断；内部代码测试仍覆盖旧类型。

## 3. 信息架构

### 交互原则（本版验收依据）

珍惜第一次使用者的注意力。页面只保留一个主标题，不再附加重复标题、口号和解释性副标题；说明只在影响当前操作时出现，完整解释收进帮助。临时填写、编辑和范围设置使用可关闭的弹窗；额外输入方式放在“更多”里，不与主要操作争夺注意力。

第一次只需粘贴主页链接，默认读取 10 条笔记及其一级评论。用户可以在“读取范围”里扩展数量或选择全部；全部指平台当前能返回的笔记，不承诺读取不可见内容，仍受单次任务超时约束。主页可能包含置顶笔记，实际范围应以导入结果为准。扩展读取与分析范围是两件事，扩展材料不会自动触发付费模型调用。

账号材料按笔记组织，而非按内部数据库类型平铺。每条笔记展示封面、标题和互动数据，点开后浏览正文、图片和对应评论；缺失封面或评论用简短空态表示。账号概览展示该账号与材料范围，并提供分析入口。旧的 JSON、文件夹导入和多种输入组合保留在内部模式。

诊断默认使用已导入的最近 10 条笔记，用户可在范围弹窗选择最近 7/30/90 天或全部已导入内容。日期筛选只纳入有可解析发布时间的笔记，明确显示未知日期排除数；没有匹配笔记时阻止执行，不悄悄扩大范围。旧导入包缺少发布时间时仍可按条数分析。实际笔记 ID、范围和确定的时间边界写入不可变输入快照，后续生成沿用此快照。

公开入口默认调用真实模型；内部演示模式保持独立。用户先使用默认路径，再逐步发现可选设置。

公开界面改成双区布局：左侧单一导航栏，中间宽内容区；删除右侧能力资产栏。

左侧从上到下为：

1. 品牌和当前账号档案选择器；
2. `开始 / 导入账号`；
3. `账号概览`和`我的笔记`；
4. `账号诊断`；
5. `分析历史`；
6. `选题库`；
7. `AI 创作`；
8. `受众模拟`。

界面不出现 Workspace、Skill、Agent、Workflow、LangGraph、checkpoint、input asset 等开发术语。帮助文案用“账号档案、账号材料、分析、选题、创作方案、受众模拟”表达。

## 4. 数据与隔离模型

### 4.1 默认用户

增加一个内部 `app_user` 所有权层。当前 API 始终使用固定的默认本地用户，不接收客户端传来的任意 user ID。这样可以保持单用户体验，同时让数据库具备多个用户分别拥有多个账号空间的范式。

### 4.2 创作者账号空间

现有 `creator_workspaces` 继续作为隔离边界，前端改称“账号档案”。每个账号档案拥有自己的：

- 小红书结构化主页；
- 历史笔记和评论样本；
- Account Diagnosis AnalysisRun；
- Topic；
- Draft（创作 Brief / 内容结构）；
- SimulationRun；
- 媒体资产和兼容资产。

当前不新增一套与 Workspace 重叠的 CreatorProfile 主表。小红书主页仍是该空间内的结构化输入资产；账号昵称同步到 Workspace 名称，用于账号切换器展示。

### 4.3 历史保留

生成结果继续遵循“生成快照不可变、用户编辑单独保存”的边界。关闭入口不会删除任何旧记录。数据库 migration 只做向前兼容变更。

## 5. 小红书 URL 导入

### 5.1 用户体验

开始页只要求用户粘贴小红书用户主页 URL 或用户主页短链。提交后展示明确阶段：

- 校验链接；
- 准备浏览器；
- 等待扫码登录；
- 正在读取主页和笔记；
- 正在整理正文、评论和封面；
- 已创建账号档案；
- 失败及可执行的修复提示。

抓取任务不能静默无限重试。默认限制笔记数量和并发，默认只抓一级评论，不抓二级评论，并明确提示用户不要高频反复提交。

### 5.2 后端实现

后端新增产品特定的 XHS capture job，不提供通用命令执行能力。任务只接受经过校验的小红书主页 URL、有限的笔记数量和是否抓取一级评论。后端使用固定 MediaCrawler 目录、固定命令模板和后端生成的输出目录，客户端不能提交本地路径或命令参数。

任务完成后，后端复用现有 parser 和 `XhsOfflineImportService`，直接创建结构化小红书主页、派生历史笔记、评论样本及封面媒体资产。前端不再要求用户手动选择 JSON 或文件夹；离线文件包入口作为内部回退能力保留但从公开页面隐藏。

### 5.3 运行环境限制

扫码登录浏览器运行在抓取后端所在机器。若主平台部署在英国而抓取要求中国大陆网络，则抓取 worker 应部署在受控的中国大陆机器，通过同一任务表或受控内部接口回传结构化包。当前本地 demo 可以让主后端直接拉起本机浏览器；不能宣称远程 VPS 已解决扫码与网络问题。

## 6. 分阶段实施

### Slice A：文档与产品模式开关

- 写入本执行手册；
- 增加明确的 creator-focused 产品模式常量；
- 旧组件、API、workflow 和测试不删除。

验收：代码中可清楚区分公开产品入口和保留的内部能力；旧模块仍可编译。

### Slice B：单栏公开产品壳

- 移除右栏渲染；
- 左栏只展示聚焦主链路；
- 标题、帮助和空态去除开发者术语；
- 默认进入“开始 / 导入账号”或账号诊断。

验收：页面中不再出现热点分析、视频质量诊断、Skills、Agents、Workflows；中间内容区变宽；账号诊断、选题、创作和模拟仍可打开。

### Slice C：账号档案作为顶层隔离单位

- 前端加载账号档案列表并支持切换；
- 新建账号档案创建独立 Workspace；
- 切换后重新加载该空间内全部内容资产和运行历史；
- 增加默认用户所有权 migration。

验收：两个账号档案之间的分析、选题、Draft 和 SimulationRun 不串数据；刷新后仍停留在有效账号档案。

### Slice D：URL 导入任务

- 增加 capture job 表、repository、service 和 API；
- URL 严格校验；
- 固定低并发、有限数量、一级评论；
- 持久化任务阶段、错误和结果资产 ID；
- 接入 MediaCrawler 与现有 parser/import service；
- 前端开始页展示登录和抓取状态。

验收：测试 runner 可以完整模拟成功、等待登录、失败和重启恢复；本地真实 runner 能从主页 URL 产出账号档案，不要求用户手工搬运 JSON。

### Slice E：主链路整理

- 账号诊断优先读取当前空间的小红书结构化主页；
- 分析历史公开视图只展示账号诊断；
- 诊断生成的 Topic 自动进入当前账号选题库；
- Topic → Brief → Structure 的入口统一为“AI 创作”；
- 受众模拟从保存的 Topic 或 Draft 发起并回到当前账号空间。

验收：新账号从导入到受众模拟可以连续完成，刷新任何页面都不会丢失已生成资产。

### Slice F：回归与文档收口

- 增加公开导航、账号切换、URL 校验、capture job、数据隔离和完整主链路测试；
- 保留旧 workflow 单元测试；
- 更新 PRD、产品设计、状态清单和 README；
- 将旧的开发者工作台说明标记为内部/历史设计，不与公开产品说明混写。

验收：后端 lint/test、前端 lint/test/build 全部通过，文档对公开能力的描述一致。

## 7. 明确不做

本次不做登录、注册、权限、协作、通用爬虫平台、任意 URL 抓取、任意命令执行、批量抓取、批量 workflow、热点分析重做、视频质量诊断重做、用户可编辑 Skill/Agent/Workflow、通用 nodegraph 编辑器或部署基础设施。

## 8. 风险与停止条件

### 当前实施状态

公开单栏导航、账号空间选择、新建账号、后端导入任务、笔记卡片与详情弹窗、分析范围筛选及快照、选题到创作/模拟入口已实现。默认模型调用为 live，旧开发者界面通过 `?internal=1` 保留。API 的 `noteLimit: 0` 明确表示全部可见笔记；仍采用单并发和 20 分钟超时，不保证平台会提供全部笔记。导入任务读取真实爬虫日志更新登录状态；后台退出会请求终止抓取进程组，重启后中断任务被标记失败，由用户重新发起。

自动化回归和真实平台验收分开记录：单元/接口测试使用测试模型与本地包，不消耗真实抓取或模型额度。真实登录抓取尚待真人验收。当前图文仅保证可用封面、正文和一级评论，笔记多图轮播取决于未来扩展的导入格式。既有混合账号的历史 Workspace 不做猜测式拆分；新的 URL 导入禁止向已有账号空间写入另一个账号，旧账号没有稳定 ID 时以昵称进行兼容检查，改昵称场景需内部整理。
