# 两账号完整创作路径实测：增强是否值得（2026-10-17）

## 结论先行

四条路径都没有形成“试读后最终稿”：QSheep／一粒鱼分别测试单次生成与当前三步增强，首稿全部交付、首次采用保存全部成功，试读全部返回，第二轮改稿全部返回空白或残缺标签。不能把四份首稿叫最终稿，也不能用快速失败的总时间证明增强等待可接受。

当前最优先不是继续处理“很多／往往”等局部措辞，而是让第二轮创作可靠交付。建议保留手动参考、来源归属、版本与人工采用；保留按需试读；暂停把“作者陈述提取＋逐句事实编辑”作为每次写作的必经增强，待用户决定后再改默认。这一轮没有改产品算法、提示或默认模型。

## 范围与可比性

- DeepSeek 配置模型与18次回执均为 deepseek-flash，非思考，temperature 0.3；创作／事实编辑max_tokens 1800，独立试读1200。没有Qwen／跨模型回退、自动重试或失败后重抽。总89,978 tokens，实际费用未获账单，不估算扣费。
- 每账号同一创作要求、同一账号诊断和同一原笔记；每组首稿的系统提示及模型参数相同，提示1646字符。因各用独立作品／会话，稿件ID、创建时间、消息来源ID及派生hash不同，不声称整个请求逐字相同。简单组只在评测实例中关闭生成后的事实编辑；不是更换另一份“好提示”。
- QSheep：保研／出国、目标模糊时如何比较；原文《如果你还在摇摆保研出国，分享三个判断逻辑》及10月16日诊断。固定“申请规划型”“经历共鸣型”两位已保存读者，并行独立试读。
- 一粒鱼：普通实习如何完成小改进；原文《大厂想要的是能跑完整个闭环的超级个体》及10月16日诊断。只选确实相关的“AI行动派”一位，不拿金融申请／博士读者凑数。
- 读者只看当前稿和人物设定，不输入历史原评论。使用定向试读问题“读完你知道怎么开始了吗？哪里仍阻碍你行动？”，所以本轮人物发言是定向审阅，不是自然评论频率预测。无推荐模型、讨论、总结或新人物生成。
- 每组固定采用首个公开发言作为改稿参考，不挑“最有利”的意见；QSheep另一位发言也保留。本轮没有验证全群聊／访谈UI；仅测试真实后端会话、反馈引用、实际DeepSeek和API保存。
- 两组首稿独立采样，不能把不同初稿文风归功于事后编辑；增强真正改了什么，以同稿编辑前后差异为准。只各一次，不推算稳定成功率。
- 基于开发服务真实库的只读备份在临时目录测试；不进入应用lifespan、不恢复既有后台任务。产品库、旧稿与用户历史不改。临时库已随进程清理；只留忽略目录中的回执。

## 为什么没得到最终稿：证据和未确定的原因

四个改稿原始content分别为：
- QSheep单次：一段空格，后面仅剩“[话题]# #保研[话题]# #26fall[话题]# #留学申请季[话题]#”。
- QSheep增强：537个空格。
- 一粒鱼单次：497个空格。
- 一粒鱼增强：593个空格。

没有被校验丢弃的完整文章；放宽必填字段无法恢复不存在的正文。会话仍保留原首稿候选，失败没有自动覆盖它；界面所得通用失败文案是“协作角色本轮未能完成，请从会话继续补充或重试。”，没有解释空输出，与诊断证据不匹配。

[DeepSeek官方JSON输出说明](https://api-docs.deepseek.com/zh-cn/guides/json_mode/)明确提示该模式可能返回空content。本次系统提示已经含JSON和格式示例，不能套用“没写JSON”解释；官方的概率性提醒也解释不了这组四次全失败的具体诱因。

本地可确认的上下文负担：
- 改稿时同一正文至少出现4遍：writingFocus.baseBody、writingFocus.readerMessage.sourceTarget.body、creativeBrief.target.body，以及真实assistant历史渲染的文章。
- QSheep首个参考包11989字符，改稿包增到16486／16018字符；一粒鱼9135增到13394／14224字符，此外还附多轮历史。
- 原助手JSON结果在后续对话里被转成面向用户的自然语言，再要求模型回到JSON输出；这是格式示范不一致的候选因素，不是已证明因果。真实角色本身应该保留，不能简单把全部历史升为user事实。

**待验证假设**是第二轮上下文组织与JSON模式交互，而不是已证实的“token超长”“必填字段太严”或某个小词句。当前没有做去重／格式重放的额外付费A/B，不把推测写成根因。

## 整篇质量得失

### QSheep

单次首稿的优点是直接承接历史真实评论，三件查证动作具体：本校规则与去向、项目背景要求、时间线。没有编造下周关闭或录取结果。结尾将原文“什么时候开始都不晚”接回查证，而非完全清空原有立场。

问题是仍偏清单化，材料更偏“可行性排除”而不是“两个选项都可行时如何取舍”；自动带26fall标签可能机械继承旧材料，不应视为当前申请季已确认。开场“很多人的真实处境”是泛化，不是调查证据。

增强首稿更简洁，直接回应想不清方向时的焦虑，没有机械附话题。可是这些优点在起草阶段就存在，事实编辑没有创造它们。编辑唯一改动为：
> 最难受的不是选哪个 → 最难受的往往不是选哪个

编辑理由称原文没有“作者被问及规划答不上来”的经历，但原句主语是“你”，是面向读者的场景，不是明确的作者亲历。这是可疑误判；增加“往往”也没有获得群体频率依据。它没有补足文章真正缺少的取舍判断。

“申请规划型”问查证顺序与节点参照；“经历共鸣型”关心查完仍不确定时怎么面对代价和内耗。简单组两人存在实质角度差异，证明按需试读能揭示整篇缺口。增强组两人却都集中在“两条路都可行时怎么选”，本轮未体现同样差异，不能只因为用了两个人就称为多视角成功。

### 一粒鱼

单次首稿保留了真实候选人通过配置模板、与产研核对并降低错误的动作链，AI能帮整理／起模板、不能代替真实验证也讲清楚。标题可用，不再是“建议版本”。

明显事实问题仍出现：
> 很多应届生跟我说，自己简历上只有一段普通实习……

当前要求只指定服务应届生，不证明作者收到过这些咨询。另把“前60份清北”等原素材情境直接写成一般招聘事实，范围过宽。不能只检查新增数字，忽略有来源但泛化了适用范围的断言。

增强首稿动作更鲜明：记录小麻烦、做粗糙版本、找人试用，再说明AI分工。这同样是它的首次采样，不是事实编辑的贡献。额外两次调用28句全keep，正文逐字未改；所以不能拿“没有跟我说”证明编辑删掉了虚构亲历。

增强稿829字符，任务约500字，明显比简单稿625字符更长；“不用等权限，不用等排期”不适用于真实工作权限／数据边界。两周是作者给读者的建议时盒，不是虚构截止日期，不应机械判为事实幻觉；问题是文章没解释为何这个时盒适合当前读者。结尾又把困难归结为“有没有跑完”，稍显训诫。

AI行动派两次都问“具体怎么问AI、输出长什么样、怎么迭代”。这不是换语气凑差异，而是指出全文共同的最大缺口：文章告诉人要用AI，却没有展示一个可开始的实例。本轮改稿失败，无法证明意见最终让文章变好。

### QSheep · 单次生成

还不知道以后想做什么，先怎么比较保研和出国

上一篇写保研和出国怎么比较，评论区有人问：如果我现在还具体不到毕业后想成为的样子，又该怎么选？

这个问题我认真想过。因为“想清楚再选”听起来对，但推免材料不等人，很多人的真实处境是：还没想清楚，时间已经到了。

那就不先问“我想成为谁”，先问三件现在就能查证、能比较的事。

第一件，你所在学校、专业的推免规则和往年去向。绩点怎么算、名额怎么分、能保到本校还是外校、往年和你背景相近的人去了哪里。这些不是听来的“保研很容易”或“保研只能留本校”，是你能去学院官网、问辅导员、找直系师哥师姐核实的。查完你会知道：保研这条路，对你到底是宽还是窄。

第二件，你想申的方向，对本科背景和先修课的要求。不是“国外学校好不好”，而是“我这套背景，能申到哪一档、哪个专业”。去翻目标项目官网的录取要求、课程设置，再找一两个真实读过的人问。这一步做完，出国对你就不再是一个模糊的向往，而是一个有门槛、有条件的选项。

第三件，两条路各自要你付出的时间。保研看的是前几年绩点和材料节点，出国看的是语言、文书、推荐信和申请季。把它们摊在同一张时间表上，你会看到哪条路现在开始还来得及，哪条路其实已经错过窗口。

这三件事查完，你可能还是不知道以后想做什么。没关系。它们不能替你决定，但能让你在“我还不确定”的前提下，知道自己手里有哪些牌、哪张牌现在还能打。

我原来那篇说，完整思考过之后，什么时候开始都不晚。现在我想补一句：想不清楚的时候，先去做能查证的事，答案常常是在查的过程中慢慢清楚的。

### QSheep · 当前三步增强

还不知道以后想做什么，先怎么比较保研和出国

推免材料要交的那几天，最难受的往往不是选哪个，是别人问你「以后想做什么」，你答不上来。

我原来那篇写的是四个判断维度，前提是你至少有一个模糊的方向。可如果连这个都没有呢？我现在的想法是：方向不清楚的时候，不要先逼自己选，先把两条路各自会通向哪里查清楚。

第一件事，查你自己学校、自己专业的过往案例。不是查「保研能去哪些好学校」，是查你们专业上一届、上上届，和你排名、背景接近的人，实际保到了哪里、什么专业。这个信息在学院教务、往届名单、学长学姐那里都能问到。它决定的是你保研这条路的真实上限，而不是想象里的上限。

第二件事，查你想申的方向，对本科背景和先修课的要求。很多项目会写明需要哪些课程、什么背景。你对着自己的成绩单看一遍，就知道自己现在够不够、还差什么。这一步不用等想清楚职业，只用看事实。

第三件事，把两条路的时间线并排写下来。保研的夏令营、预推免、材料截止是什么时候；申请要什么时候考语言、什么时候交材料。写在同一张纸上，你会看到哪条路的时间更紧、哪条路还留有余地。

这三件事做完，你可能还是不知道以后想做什么。但你会知道：哪条路你现在够得着，哪条路需要补什么，哪条路的时间不允许你再拖。

我依然觉得，方向这件事急不来。但在方向清楚之前，先把能查的事实查清楚，至少不会因为信息不足而做错决定。

至于最后选哪个，还是得你自己来。

### 一粒鱼 · 单次生成

没做过大项目，也能讲清楚一件小改进

很多应届生跟我说，自己简历上只有一段普通实习，没做过什么大项目，面试里根本没什么可讲。

但大厂筛简历的时候，前60份都是清北递来的，每个人都有2-3段比较匹配的实习。从用人方来看，大厂不缺聪明人。缺的是能从发现问题、验证方案、做出原型、拿到用户反馈一路走完的人。

所以问题不在于你的实习够不够大，而在于你有没有在一件小事上跑完过闭环。

原笔记里那个拿到商家运营岗sp offer的候选人，是一个非常普通211的学生，只有一段不够匹配的中小型电商活动运营的实习经历。她出彩的点，是她发现了平台一个大促链接的手动配置容易出错，自己利用闲暇时间做了一个配置模版，和产研去对，最后真的降低了配置错误率。

这件事不大，但它能讲清楚：问题是什么、她做了什么、谁用了、结果怎么样。

如果你现在只有普通实习，可以先做三件事。

第一，翻一遍你实习里重复出现、容易出错、需要手动补位的环节。不用找战略级问题，就找那种“每次都要重新来一遍”的小事。

第二，把你已经做过的动作写下来，哪怕只是整理了一份检查清单、改了一版模板、跟同事对过一次流程。写清楚你发现了什么、改了什么、谁在用。

第三，用AI帮你把这件事往前推一步。比如让它帮你梳理流程里的重复节点、生成一版模板初稿、模拟用户会怎么反馈。但AI不能替代你去确认这件事到底有没有人用、有没有真的减少出错。判断和落地，还是得你自己来。

小改进能不能讲清楚，不取决于它多大，取决于你有没有从头到尾把它跑完。

### 一粒鱼 · 当前三步增强

没做过大项目，也能讲清楚一件小改进

很多应届生会卡在同一个地方：简历上只有一段普通实习，没主导过项目，没拿过什么结果，那我能讲什么？

其实大厂不缺聪明人，也不缺漂亮的实习title。它缺的是能从发现问题、验证方案、做出原型、拿到用户反馈一路走完的人。这个闭环不一定来自大项目，它完全可以来自一件很小的事。

原笔记里那个拿到商家运营岗sp offer的候选人，实习经历甚至不够匹配，她出彩的点是发现平台一个大促链接的手动配置容易出错，自己利用闲暇时间做了一个配置模版，和产研去对，最后真的降低了配置错误率。这件事不大，但它有完整链条：发现问题、做出东西、找人验证、拿到反馈。

如果你现在只有普通实习，可以先做三件事。

第一，把实习里让你觉得“这里有点麻烦”的瞬间记下来。不是记“我学到了什么”，而是记具体动作：哪个链接要手动配、哪张表每天要重复填、哪个流程每次都要问同一个人。小改进的起点不是宏大洞察，是一个反复出现的麻烦。

第二，挑一个你能在两周内做出粗糙版本的问题。不用等权限，不用等排期，先做一个模板、一张自动填表的脚本、一份把常见问题整理清楚的文档。重点不是它多完美，而是它能被拿给别人看、被试用、被指出哪里不对。

第三，拿着这个东西去找真实的人对一次。可以是带你的mentor，可以是隔壁岗位的同事，也可以是产研。问的问题要具体：这个能不能减少你一步操作？哪里还不好用？你愿不愿意用下一次？拿到反馈后改一版，这件事就能讲清楚了。

AI在这里能帮哪一步？它能帮你把粗糙版本做出来。比如你不熟公式，可以让它帮你写表格脚本；你不确定模板怎么搭，可以让它先给几个结构；你整理文档，可以让它帮你归类常见问题。它不能替代的是：判断这个问题值不值得做、去找真实的人验证、根据反馈决定改哪里。这三步还是你自己的。

所以，没有大项目不是问题。问题是你有没有把一件小事跑完。哪怕只是让一个手动配置少错一次，只要你能讲清楚你发现了什么、做了什么、谁用了、改了什么，它就是一个能讲清楚的小改进。
